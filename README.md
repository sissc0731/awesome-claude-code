## 💬 提示词精选

### 代码生成
```
帮我写一个 [语言] 的 [功能]，要求：
- 处理边界情况
- 添加错误处理
- 写清楚注释
```

### 代码审查
```
审查这段代码，关注：
- 安全漏洞
- 性能问题
- 可读性
- 最佳实践
```

### Bug 调试
```
这段代码预期输出 [X]，实际输出 [Y]。
帮我找出原因并修复。不要猜测，先分析再动手。
```

### 重构优化
```
重构下面这段代码，目标：
- 提高可读性
- 减少嵌套
- 不改变行为
```

### 写测试
```
给这个函数写单元测试，覆盖：
- 正常输入
- 边界值
- 异常情况
```

### 写文档
```
给这个项目生成 README，包括：
- 项目简介
- 快速开始
- API 文档
- 示例代码
```

### 翻译
```
把 README.md 翻译成中文。
- 代码块不要翻译
- 技术术语用通用译法
- 保持 Markdown 格式
```
